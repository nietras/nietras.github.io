[Sep 0.18.0 was released November 11th,
2026](https://github.com/nietras/Sep/releases/tag/v0.18.0) with update to add
target `net11.0` with runtime-async=on, a new SIMD parser, more optimizations,
several fixes incl. edge case correctness issues, see the linked release notes
for more details. There have been several other minor releases since 0.12.0,
these can also be checked out at
[releases](https://github.com/nietras/Sep/releases) on GitHub.

## Sep Performance Progression

It's a little hard to compare versions here as seen in below chart, since I have
also switched CPU from 9950X to 9950X3D2, since needed to test the latter for
work related ML inference. Improvements in speed are not due to .NET JIT
improvements but due to new CPU and new optimizations, of which some depend on
.NET 10+ features.
